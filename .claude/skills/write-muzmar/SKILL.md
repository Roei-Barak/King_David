# מדריך כתיבה — מחזמר "מזמור לדוד"

## עקרונות יסוד (לא לחרוג בלי אישור מפורש)

**תזה:** דוד כדמות מופת של אמונה דרך ייסורים. חוט הזהב: "כל עצירת יד מולידה כינור."

**שלוש השפות — חוק ברזל:**
| שכבה | רגיסטר | דוגמה |
|------|---------|--------|
| דיאלוג | פרוזה מליצית מקראית | "מַה לִּי וְלָכֶם בְּנֵי צְרוּיָה" |
| מונולוג פנימי | שיר חופשי בסגנון תהילים | שורות קצרות, חזרה, עלייה וירידה |
| שיר מוזיקלי | חרוז קבוע + מטר | "הֲלָלוּיָהּ / עַל כָּל אֲשֶׁר הָיָה" |

**אסור לערבב** — מונולוג בחרוז, דיאלוג בשיר חופשי = שגיאה.

## מצב א׳ — כתיבת סצנה חדשה

### קבל מהמשתמש:
- פרק תנ"כי (כגון: שמ"א כג)
- דמויות מרכזיות
- מה רגש/נושא מרכזי

### בדוק לפני הכתיבה:
```bash
# וודא שהסצנה לא קיימת
ls /home/user/King_David/scenes/ | grep -i <שם>
# קרא את מפת המזמורים הרלוונטי
grep -A3 "פרק <מספר>" /home/user/King_David/sources/tehillim-map.md
# קרא את המדרשים הרלוונטיים
grep -A5 "<שם-דמות\|שם-אירוע>" /home/user/King_David/scenes/scene-midrashim.md
```

### מבנה סצנה:
```markdown
# כותרת — שם הסצנה
### מקור: שמ"א כג, טו-יח | ~X דקות

## חלק א': כותרת חלק
**שמואל א' כג, טו | ~X דקות**

*(הוראות במאי: בעברית מודרנית — מה קורה פיזית)*

**דָּוִד** *(תנועה)*:
"דִּבּוּר בְּפְּרוֹזָה מְלִיצִית..." *(שמ"א כג, יז)*

*(תגובה)*

## מזמור — [שם] *(מונולוג פנימי)*
*(שיר חופשי — כמו תהילים)*
שורה קצרה
עוד שורה
הרחבה — ואז...
שיא

## שיר: "כותרת שיר" *(אם יש)*
*(חרוז + מטר קבוע)*
שורה א — ריתמוס
שורה ב — חרוז
```

### כללים קריטיים:
- כל ציטוט מקראי: `*(שמ"א כג, יז)*` — מיד אחרי הציטוט
- מדרש לא מאומת: לסמן `[לאמת]`
- **אסור להמציא פסוקים** — אם לא בטוח, [לאמת]
- קול ייחודי לכל דמות (ראה `characters/` לפירוט)

## מצב ב׳ — Script Doctor: חשיפת פוטנציאל (לא ביקורת)

> **הגישה:** לא עורך שמחפש טעויות — **שותף ליצירת מופת** שחושף פוטנציאל לא ממומש. השאלה אינה "מה לא בסדר?" אלא **"אילו רבדים, פסוקים, מדרשים, קונפליקטים ורגשות קיימים כאן — ועדיין לא נחשפו?"** המחזה בשלב איסוף עושר: היוצר רוצה כמה שיותר אופציות, והוא יבחר בעצמו בעריכה.
> הפרומפט העצמאי המלא (להדבקה במודלים אחרים): `concept/prompt-scene-workshop.md` — הסקיל הזה פועל באותה רוח.

### חוקי ברזל:
1. **לא למחוק** — חלש? מעמיקים
2. **לא לקצר** — ארוך? מבדלים; הגרסה המשופרת ≥ המקור, לעולם לא קצרה ממנו
3. **לא לשנות מבנה** — לשפר מה שיש
4. **חוזר על עצמו?** — לתת לכל מופע משמעות אחרת

### ששת הצעדים (לכל סצנה, לפי הסדר):

**א' — אבחון (5 שורות):** הלב הדרמטי · השאלה של הסצנה · **איזה מזמור נולד כאן ולמה דווקא כאן** · מה כבר ברמת מופת · איזה פוטנציאל טרם נחשף.

**ב' — שיפור שפה ודיאלוג:** החלפת מודרנית במקראית · הוספת תת-טקסט (מה הדמות *לא* אומרת) · קול ייחודי לכל דמות · בדיקה אם פסוק אמיתי מחליף משפט מומצא.

**ג' — הרחבת דיאלוגים:** קונפליקט פנימי גלוי יותר · רגעי שתיקה מפורשים · תגובות חדשות · רגעים שדמות **כמעט אומרת — ועוצרת**.

**ד' — פסוקים ומדרשים שלא נוצלו:** ≥5 פסוקים עם מראה מקום + איך לשלב · ≥2 מדרשים עם `[לאמת — מקור משוער]` + איך להפוך **לפעולה דרמטית**.

**ה' — גרסה מורחבת מלאה:** הסצנה מחדש עם כל השיפורים (יכולה להיות פי 2). בסופה דו"ח: מה נוסף ולמה · פסוקים ששולבו · רגעים חדשים · מה סומן [לאמת].

**ו' — 3 שאלות לבמאי:** הכרעות שהיוצר יחליט בעריכה.

### פעולות עזר:
```bash
cat /home/user/King_David/scenes/<שם>.md
# ציטוטים ללא מקור? עברית מודרנית בפי דמויות? ("בסדר", "רגע", "אז", "בעצם", "נו")
```

### לכל שיפור — להסביר *למה*:
```markdown
*(שיפור: הפסוק המקורי "לא ידעתי" הוחלף ב"מה לי ולכם" כי רגיסטר מקראי)*
```

### מבחני הגדולה (להפעיל על כל סצנה):
| מבחן | השאלה |
|------|--------|
| שתיקה | אחרי איזה רגע אמורה להיות שתיקה באולם? האם הסצנה *הרוויחה* אותה? |
| דמעות | לא "האם דוד סובל" — **האם הקהל סובל איתו?** |
| ציטוט | אילו משפטים יצוטטו בדרך הביתה? אם אין — היכן לחפש? |
| כינור | האם המזמור עולה **מתוך שבר** — לא מניצחון? |
| "כמעט מתחלף" | האם יש רגע שדוד כמעט נהפך למישהו אחר — וחוזר? |
| קהל-2026 | למה ישראלי היום צריך את הסצנה? (חיים, לא פוליטיקה) |
| תהילים | האם הצופה יקרא את המזמור אחרת אחרי הסצנה? |

## מצב ג׳ — כתיבת שיר

### קבל מהמשתמש:
- תפקיד דרמטי (I WANT / לאמנט / שיר ניצחון / דואט...)
- דמות שרה
- פסוקי תהילים רלוונטיים (מ-`sources/tehillim-map.md`)
- לחן/ז׳אנר אם ידוע

### בדוק קודם:
```bash
cat /home/user/King_David/songs/song-map.md
grep -A5 "<שם-שיר\|תמונה>" /home/user/King_David/songs/song-map.md
```

### מבנה שיר (חרוז):
```
## בית א׳
[4-6 שורות, מטר קבוע, חרוז ABAB או AABB]

## פזמון
[4 שורות, חוזר — פשוט וחזק]
[ניתן לזמר מהר]

## בית ב׳
[אותו מבנה — תוכן מתקדם]

## פזמון

## שיא (bridge)
[שינוי מטר — עוצמה]

## פזמון (גרסה שינוי קל)
```

### דרישות שיר:
- לפחות פסוק תהילים אחד משולב (במקור, לא תרגום)
- מטרה דרמטית: מה השיר מקדם בעלילה?
- לסמן בגוף הקובץ: `**[תפקיד דרמטי: ...]**`
