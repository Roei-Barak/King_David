# דוגמאות כתיבה למזמור לדוד

52 דוגמאות חדשות לדיאלוג ופעולה, אחת לכל תמונה, על בסיס השלד והטיוטות הקיימות. הצעות אלה אינן מחליפות החלטות יוצר. השירים נשארים לשלב נפרד.

[כל הדוגמאות ברצף](scene-examples.md)

[מסמך הדוגמאות בגוגל דוקס](https://docs.google.com/document/d/1yMmJFonCb6eM7Ia2YUFPo-2E1SFBhTn2nKJATx14-7s/edit?usp=drivesdk)

המסמך מכיל דוגמאות מקוצרות למשחק ושכתוב, ואינו מחליף את נוסח המחזה. עימוד Word הנוכחי הוא 35 עמודים; אין בכך מדידת זמן במה.
