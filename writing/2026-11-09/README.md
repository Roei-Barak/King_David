## מתחילים כאן

1. קרא את תחילת `writing-workbook.md` או את המסמך בגוגל דוקס: ההחלטות, מפת הרצפים ותוכנית השבועות.
2. פתח את [תמונה 01](scenes/scene-01.md). הכרטיס מציג את התפקיד הדרמטי, הפעולות ומשימת השכתוב; מתחתיו נמצא הנוסח הקיים מטיוטה 2.
3. כתוב את הדיבור לכבשה בקול שלך, קרא את המעברים בין המרעה לשמואל בקול, וסמן התקדמות בטבלת התמונות.
4. בסוף מפגש רשום ביומן שבסוף הקובץ מה שינית, מה עוד פתוח ומה תהיה הפעולה הבאה.
